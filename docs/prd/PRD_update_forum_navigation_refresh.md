# PRD：更新日志主题、帖子吧入口与主页导航交互优化

## Problem Statement

应用内更新日志弹窗的 Markdown 文本使用固定黑色，深色模式下不可读。帖子卡片底部的吧头像和吧名虽已呈现，但部分调用方没有完成导航回调绑定，无法稳定进入对应吧内页。底部四个主 Tab 缺少重击当前 Tab 的刷新行为。首页最近浏览贴吧区域使用固定 Row 并置于可滚动内容之外，窄屏会溢出且不会随主页内容滚动隐藏，外观与完整版吧内页的通用 Tab 不一致。

## Solution

1. 更新日志弹窗中的标题、正文和 Markdown 片段全部使用应用颜色资源，自动跟随浅色/深色主题。
2. 所有使用帖子卡片的列表都绑定底部吧入口的导航回调；点击吧头像或吧名进入当前设置选择的吧内页版本，并传递已知头像。
3. 底部首页、动态、消息、我的四个 Tab 在重击当前已选项时刷新各自当前可见的主数据；刷新失败保留旧内容并显示轻量提示。
4. 首页最近浏览贴吧保留头像，改为可横向滚动的紧凑圆角 Tab，视觉对齐完整版吧内页的通用 Tab；该区域放入首页可滚动内容，随主页上滑隐藏，点击直接进入对应吧内页。

## User Stories

1. 作为深色模式用户，我希望更新日志弹窗的所有文字都清晰可读，以便了解版本变更。
2. 作为浅色模式用户，我希望更新日志保持现有清晰层级，以便阅读不受影响。
3. 作为帖子列表用户，我希望点击帖子底部的吧头像可以进入对应吧内页，以便浏览同吧内容。
4. 作为帖子列表用户，我希望点击帖子底部的吧名可以进入对应吧内页，以便不必先进入帖子详情。
5. 作为使用完整吧内页的用户，我希望从帖子卡片进入的目标保持完整吧内页，以便不丢失页面偏好。
6. 作为使用简化吧内页的用户，我希望从帖子卡片进入的目标保持简化吧内页，以便不改变页面偏好。
7. 作为首页用户，我希望重击当前首页 Tab 刷新关注吧数据，以便快速获取最新关注状态。
8. 作为动态页用户，我希望重击当前动态 Tab 刷新当前可见子页，以便更新关注、推荐或热榜内容。
9. 作为消息页用户，我希望重击当前消息 Tab 刷新当前可见消息子页，以便查看新互动。
10. 作为个人页用户，我希望重击当前我的 Tab 刷新个人资料，以便同步账号状态。
11. 作为用户，我希望刷新失败时旧内容保留且得到提示，以便不会丢失已浏览信息。
12. 作为首页用户，我希望最近浏览贴吧横向滚动而不在窄屏溢出，以便访问较多历史贴吧。
13. 作为首页用户，我希望最近浏览贴吧随主页内容上滑隐藏，以便为关注吧列表让出空间。
14. 作为首页用户，我希望最近浏览贴吧保留头像和紧凑圆角 Tab 外观，以便同时快速识别并保持与完整吧内页一致的导航语言。
15. 作为首页用户，我希望点击最近浏览贴吧直接进入对应吧内页，以便快速回访。

## Implementation Decisions

- 更新日志渲染的文本颜色由应用颜色资源提供，禁止在 Markdown 文本节点写固定黑色值；链接、正文和标题分别使用既有主题语义色。
- 帖子卡片维持单一吧入口回调，不在组件内部创建新的路由机制。全部调用方传入同一套根据吧内页版本设置选择目标页的导航逻辑。
- 底部导航使用原始 Tab 索引识别重击；只有目标索引与当前原始索引相同才发布刷新请求。正常切换仍保持现有动画和触感反馈，不附带刷新请求。
- 主 Tab 刷新使用一个轻量全局事件状态承载递增请求序号和原始 Tab 索引。页面仅响应属于自身的请求，并调用既有加载方法；不复制网络请求、分页或错误处理逻辑。
- 动态页和消息页刷新当时可见的内部 Tab，而不是盲目刷新所有内部数据源。个人页刷新已登录资料；未登录时保持已有本地展示。
- 最近浏览贴吧不是吧内内容筛选器，不维护驻留选中态。它是可点击的历史入口，保留按压反馈。
- 最近浏览贴吧使用横向 Scroll 与圆角 Tab 外观，保留头像；将其纳入首页当前 List/Grid 的可滚动内容头部，使其与完整版吧内页通用 Tab 一样随内容滚动离开视口。
- 不将首页历史入口与完整版吧内页通用 Tab 抽象成同一个复杂组件：两者的数据、选中态和行为不同，仅对齐滚动与视觉语言。

## Testing Decisions

- 更新日志的纯渲染颜色没有适合的本地单元测试 seam，使用浅色和深色模式下的设备/模拟器手工回归验证；验证正文、标题、链接和 Markdown 强调文本均不使用固定黑色。
- 帖子吧入口通过覆盖所有帖子卡片调用点的编译检查和设备点击回归验证，确认吧头像与吧名均进入由当前设置决定的吧内页。
- 重击 Tab 的事件派发与 Tab 索引映射抽为可测试的纯逻辑时，为四个原始 Tab、隐藏 Tab 映射和“切换不刷新/重击刷新”添加本地单元测试。
- 页面刷新复用已有加载函数，设备回归验证每个主 Tab 的当前可见数据刷新、旧内容保留和失败提示。
- 最近浏览贴吧验证 8 个历史条目在窄屏可横向滚动、点击可进入吧内页、页面上滑后历史入口随内容隐藏。

## Out of Scope

- 不改变 GitHub Release 网页的配色。
- 不新增或修改贴吧服务端接口。
- 不把最近浏览贴吧变成首页筛选器，也不为它增加驻留选中态。
- 不在普通切换底部 Tab 时自动刷新数据。
- 不改动完整版吧内页通用 Tab 的服务端分类、排序或请求协议。

## Further Notes

- 底部主 Tab 为首页、动态、消息、我的；首页不是信息流，而是关注吧列表页面。
- 最近浏览贴吧当前最多保存 8 项，固定宽度 Row 会在窄屏溢出；此次修复必须消除该布局问题。
